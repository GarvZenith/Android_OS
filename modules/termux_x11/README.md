# Linux Subsystem Module (Termux-X11 + Debian/Ubuntu RootFS)

This module integrates the embedded Linux terminal and X11 GUI server into the OS:
- **Termux.apk**: Terminal shell environment.
- **TermuxX11.apk**: X-Server display window renderer for XFCE / LXDE desktop applications and VS Code.

Place `Termux.apk` and `TermuxX11.apk` into `modules/termux_x11/` before building.
