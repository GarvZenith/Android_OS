# iOS Compatibility Bridge Module (TouchHLE)

This module integrates the TouchHLE Mach-O binary execution engine:
- **TouchHLE.apk**: High-level emulator for legacy 32-bit iOS `.ipa` apps and games.
- **Web PWA Bridge**: Pre-configured web app shortcuts for Apple services (iCloud, Apple Music).

Place `TouchHLE.apk` inside `modules/touchhle/` before system build.
